How It Works

Five simple steps showing how cost-aware active learning saves money.

1

Collect Transactions

Start with 12,000 card payments. Each one has a checking cost between 1 and 6 units.

2

Train Starter Model

Check a tiny starter batch of payments so the detector learns its first clues.

3

Score Value per Dollar

Measure how confused the model is on each transaction, then divide by its cost.

4

Pick Smart Checks

Investigate only the most confusing, lowest-cost transactions first.

5

Update & Catch Fraud

Retrain the detector after each batch—getting strong accuracy for far less money.

Note: All results, transactions, and costs shown in this app come from simulated (fake) data created for educational demonstration purposes.
